# 로컬 서비스 포트 컨벤션

로컬에서 여러 서비스를 동시에 실행할 때 호스트 포트가 충돌하지 않도록 서비스 번호 `n`을 사용합니다. 컨테이너 내부 포트는 제품의 기본 포트를 유지하고, 호스트 포트에만 서비스 번호를 더합니다.

## 계산 기준

| 용도 | 호스트 포트 계산식 | 컨테이너 기본 포트 |
| --- | ---: | ---: |
| Spring Boot | `8080 + n` | `8080` |
| MySQL | `3306 + n` | `3306` |
| PostgreSQL | `5432 + n` | `5432` |

애플리케이션 포트는 현재 각 서비스에 지정된 `8081`부터 `8087`까지를 기준으로 하므로 `8080 + n`입니다.

## 서비스별 로컬 포트

`-`는 해당 서비스에서 사용하지 않는 DBMS입니다.

| n | 서비스 | 애플리케이션 | MySQL | PostgreSQL | 
| ---: | --- | ---: |------:|-----------:| 
| 1 | auth-service | 8081 |  3307 |          - |
| 2 | order-service | 8082 |  3308 |          - |
| 3 | payment-service | 8083 |  3309 |          - |
| 4 | product-service | 8084 |     - |       5436 |
| 5 | wms-service | 8085 |     - |       5437 | 
| 6 | oms-service | 8086 |     - |       5438 |
| 7 | scm-service | 8087 |     - |       5439 |
